# 本地运行说明（前端 + 演示后端）

本仓库是一个单仓库项目：

```
iplat-front/     前端（Vue 3 + Element Plus）
iplat-backend/   后端（RuoYi-Vue-Plus v5.4.1 + DMS 演示接口）
```

> 真实 DMS 业务接口属于公司私有后端，开源版 RuoYi-Vue-Plus 并不包含。
> `iplat-backend` 中的 DMS 接口是按前端调用补充的演示实现，返回内存模拟数据，
> 用于登录、菜单导航和页面展示；新增/修改等操作不会真正持久化。

---

## 1. 环境要求

| 组件 | 版本 / 地址 | 说明 |
| --- | --- | --- |
| Node.js | >= 18.18 | 前端 |
| JDK | 17 | 后端 |
| Maven | 3.8+ | 后端打包 |
| MySQL | `127.0.0.1:3306`，`root/root` | 数据库 `ry-vue` |
| Redis | `127.0.0.1:16379`，密码 `ruoyi123` | `start-local.sh` 会自动拉起 |

Redis 使用 16379 而不是默认 6379，避免影响本机已有数据。

---

## 2. 首次初始化数据库

MySQL 中创建数据库并导入三份 SQL（只需执行一次）：

```bash
# 1. 建库
MYSQL_PWD=root mysql -uroot -e \
  "CREATE DATABASE IF NOT EXISTS \`ry-vue\` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;"

# 2. 框架表 + 基础数据
MYSQL_PWD=root mysql -uroot --default-character-set=utf8mb4 ry-vue \
  < ../iplat-backend/script/sql/ry_vue_5.X.sql

# 3. 工作流表
MYSQL_PWD=root mysql -uroot --default-character-set=utf8mb4 ry-vue \
  < ../iplat-backend/script/sql/ry_workflow.sql

# 4. 演示用 DMS 菜单（可重复执行）
MYSQL_PWD=root mysql -uroot --default-character-set=utf8mb4 ry-vue \
  < ../iplat-backend/script/sql/iplat_mock_menus.sql
```

如果 MySQL 密码不是 `root`，请同步修改
`../iplat-backend/ruoyi-admin/src/main/resources/application-dev.yml`。

---

## 3. 启动后端

```bash
cd ../iplat-backend

# 首次运行需要打包
mvn -pl ruoyi-admin -am package -DskipTests

# 启动
./start-local.sh
```

脚本会：

1. 如果没有运行中的本地 Redis，则在 `16379` 启动；
2. 用 JDK 17 启动 `ruoyi-admin/target/ruoyi-admin.jar`；
3. 后端监听 **18080**。

验证：

```bash
curl http://127.0.0.1:18080/auth/code
# {"code":200,"msg":"操作成功","data":{"captchaEnabled":false,...}}
```

修改过后端代码时重新打包：

```bash
mvn -pl ruoyi-admin -am package -DskipTests
```

## 5. 本地化改动清单

### 前端

- `vite.config.ts`
  - `/dev-api`、`/pows-api` 代理指向 `127.0.0.1:18080`
- `.env.development`
  - `VITE_APP_PORT`：`80` → `8081`
  - `VITE_APP_ENCRYPT`：`true` → `false`

### 后端

- `ruoyi-admin/src/main/resources/application.yml`
  - `server.port`：`8080` → `18080`
  - `captcha.enable`：`true` → `false`
  - `api-decrypt.enabled`：`true` → `false`
- `ruoyi-admin/src/main/resources/application-dev.yml`
  - Redis：`6379` → `16379`
  - 关闭 SnailJob、监控客户端、p6spy
- 新增演示代码（只用于本地）
  - `org/dromara/web/controller/mock/MockDmsController.java`
  - `org/dromara/web/controller/mock/MockEqmsController.java`
  - `org/dromara/web/controller/mock/MockPageConfigController.java`
  - `resources/mock/page-configs.json`
- 新增菜单 SQL
  - `script/sql/iplat_mock_menus.sql`
- 启动脚本
  - `start-local.sh`

### 演示接口行为

- `/dms/**`：列表类请求返回 8 条演示数据（`rows/total`），详情返回一条数据，新增/修改/删除返回成功
- `/eqms/**`：列表返回空数据
- `/system/page-config/page/{code}`：返回表格/搜索列配置；未配置的编码按模块返回通用列
- 演示数据在内存中生成，**重启后重置**

## 6. 已知限制

- PageOffice 在线编辑、PDF 预览、文件上传/下载、电子签名等依赖真实后端与文件服务，本地不可用。
- 业务表单弹窗依赖公司后端的动态表单配置，本地多为空表单；列表页展示正常。
- 设备管理（`/eqms`）只有菜单和空页面。
- 首页中的“设备档案 / 维保计划”等入口来自旧项目 mock，指向不存在的路由，点击会 404；不影响文件管理模块。
