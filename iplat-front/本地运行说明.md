# 本地运行说明（前端 + 完整后端）

本仓库是一个单仓库项目：

```
iplat-front/     前端（Vue 3 + Element Plus）
iplat-backend/   后端（RuoYi-Vue-Plus v5.4.1 + ruoyi-dms 完整业务模块）
```

后端为依据前端接口规格实现的完整参考实现：
- 真实 MySQL 业务表（44 张，`iplat-backend/script/sql/iplat_dms.sql`）
- 真实 warm-flow 审批流（提交→待办→同意/驳回/撤回，审批通过自动生效入库）
- 真实 MinIO 文件存储（附件上传/查询/打包下载）
- 页面动态配置（表格/搜索/表单列）存数据库，启动时自动导入

## 2. 首次初始化数据库

```bash
# 1. 建库
MYSQL_PWD=root mysql -uroot -e \
  "CREATE DATABASE IF NOT EXISTS \`ry-vue\` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;"

# 2. 框架表 + 基础数据
MYSQL_PWD=root mysql -uroot --default-character-set=utf8mb4 ry-vue \
  < ../iplat-backend/script/sql/ry_vue_5.X.sql

# 3. 工作流表
MYSQL_PWD=root mysql -uroot --default-character-set=utf8mb4 ry-vue \
  < ../iplat-backend/script/sql/ry_workflow.sql

# 4. DMS 业务表
MYSQL_PWD=root mysql -uroot --default-character-set=utf8mb4 ry-vue \
  < ../iplat-backend/script/sql/iplat_dms.sql

# 5. DMS 种子数据（字典/参数/审批流定义/演示数据，幂等）
MYSQL_PWD=root mysql -uroot --default-character-set=utf8mb4 ry-vue \
  < ../iplat-backend/script/sql/iplat_dms_seed.sql

# 6. DMS 菜单
MYSQL_PWD=root mysql -uroot --default-character-set=utf8mb4 ry-vue \
  < ../iplat-backend/script/sql/iplat_dms_menus.sql
```

## 3. 启动后端

```bash
cd ../iplat-backend

# 首次运行需要打包
mvn -pl ruoyi-admin -am package -DskipTests

# 启动（自动拉起 Redis 16379 与 MinIO 9000）
./start-local.sh
```

后端监听 **18080**。验证：

```bash
curl http://127.0.0.1:18080/auth/code
```

## 5. 端到端验证过的流程

- 文件库（生效/未生效/失效）、记录库、模板库列表与详情（真实分页数据）
- 文档编制新增 → 提交审批 → 审批同意 → 文件库自动入库（未生效）→ 培训生效 → 文件库生效
- 模板编制 → 提交审批 → 通过 → 模板库自动入库并生成快照
- 打印申请 → 审批 → 打印明细状态机（打印/发放/领用/交回/关闭/销毁）
- 借阅申请 → 审批 → 借阅库
- 附件上传 → MinIO → 按业务查询/打包下载
- PDF 预览（占位生成物）
- 审批驳回/撤回/终止（状态回写业务表）

## 6. 本地化改动清单

### 前端

- `vite.config.ts`：代理指向 `127.0.0.1:18080`
- `.env.development`：端口 8081、关闭接口加密

### 后端

- `application.yml`：端口 18080、关闭验证码、关闭 api-decrypt
- `application-dev.yml`：Redis 16379、关闭 SnailJob/监控/p6spy
- 新增 `ruoyi-modules/ruoyi-dms` 业务模块（约 40 个控制器 + 44 张表）
- `ruoyi-common-oss/OssClient`：去掉 `chunkedEncodingEnabled(false)`（aws sdk 2.28 异步客户端下会缺 `x-amz-content-sha256` 头，被 MinIO 拒绝）
- `script/sql/iplat_dms*.sql`：业务表 / 种子数据 / 菜单
- `start-local.sh`：一键拉起 Redis + MinIO + 后端

## 7. 已知限制

- PDF 预览为占位生成物；PageOffice 在线编辑不可用（无许可服务）
- 电子签名为演示令牌；动态表单规则引擎不执行
- 设备管理（EQMS）为最小 CRUD
- 业务规则按前端代码推导，可能与公司原实现存在差异
